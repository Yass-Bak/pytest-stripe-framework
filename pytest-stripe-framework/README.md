# Professional API Automation Framework

## Overview

This is a production-grade API testing framework for the Stripe API, designed to demonstrate Senior SDET capabilities. It features a clean, layered architecture (Client-Service-Test), robust error handling, detailed logging, Allure reporting, and CI/CD integration.

## Architecture

The framework follows a modular design:

- **Clients**: Low-level HTTP wrappers handling authentication, retries, and logging.
- **Services**: Business logic encapsulation, exposing clean methods to tests.
- **Models**: Pydantic DTOs for type-safe data transfer.
- **Schemas**: JSON schemas for strict response validation.
- **Utils**: Shared utilities for configuration, logging, auth, and retries.
- **Tests**: Functional and negative tests grouped by domain.

## Tech Stack

- **Python 3.12+**
- **Pytest**: Test runner
- **Requests**: HTTP client
- **Pydantic**: Data validation and serialization
- **Allure**: Reporting
- **Docker**: Containerization
- **GitHub Actions**: CI/CD

## Setup

1. **Clone the repository**
2. **Install Dependencies**:
   ```bash
   pip install -r requirements.txt
   ```
3. **Configure Environment**:
   Copy `.env.example` to `.env` and add your Stripe API Key.
   ```bash
   cp .env.example .env
   ```

## Running Tests

### Standard Run
```bash
pytest
```

### Parallel Execution
```bash
pytest -n auto
```

### With Allure Reporting
```bash
pytest --alluredir=reports
allure serve reports
```

### Docker Run
```bash
docker build -t stripe-tests .
docker run stripe-tests
```
